# Topic 4: Strings - Exercises

## Exercise 1: Indexing
Create a string. Print the first, middle, and last character.

## Exercise 2: Slicing
Create a string. Print the first 3 characters and the last 3.

## Exercise 3: Uppercase
Ask for a word. Display it in uppercase.

## Exercise 4: Capitalization
Ask for a sentence. Display with first letter capitalized.

## Exercise 5: Replace
Ask for a sentence. Replace one word with another. Display result.

## Exercise 6: Concatenation
Ask for first and last name. Combine and display full name.

## Exercise 7: String Length
Ask for a word. Display its length.

## Exercise 8: Find Substring
Ask for text and a word to find. Display the position.

## Exercise 9: Split String
Ask for a sentence. Split into words. Display each word.

## Exercise 10: Formatted Output
Ask for name and age. Display formatted message using f-string.

# Topic 2: Variables - Exercises

## Exercise 1: Store and Use
Create three variables for numbers. Calculate their sum and display it.

## Exercise 2: Currency Conversion
Create a variable for USD amount (100). Create a variable for exchange rate (0.92). Calculate EUR equivalent.

## Exercise 3: Rectangle Area
Create variables for width (5) and height (3). Calculate area. Display: `Area: 15`

## Exercise 4: Name Concatenation
Create variables for first name and last name. Display full name.

## Exercise 5: Temperature Conversion
Create a variable for Celsius. Convert to Fahrenheit. Display both.

## Exercise 6: Percentage
Create variables for score (85) and total (100). Calculate percentage. Display: `85%`

## Exercise 7: Shopping Cart
Create variables for three item prices. Calculate subtotal, tax, and total.

## Exercise 8: Age Calculation
Create variables for birth year and current year. Calculate age.

## Exercise 9: Update Variable
Start with a value. Modify it based on some condition. Display before and after.

## Exercise 10: Multi-step Calculation
Create variables for base salary and bonus percentage. Calculate final salary after bonus.

# Topic 3: Input - Exercises

## Exercise 1: Basic Greeting
Ask for the user's name. Display: `Hello, [name]!`

## Exercise 2: Age Calculation
Ask for birth year. Calculate age (2026 - birth year). Display age.

## Exercise 3: Sum Two Numbers
Ask for two numbers. Display their sum.

## Exercise 4: Temperature Conversion
Ask for Celsius. Convert to Fahrenheit. Display both.

## Exercise 5: Rectangle Area
Ask for width and height. Calculate and display area.

## Exercise 6: Grade Average
Ask for three test scores. Calculate and display average.

## Exercise 7: Price with Tax
Ask for price. Add 10% tax. Display total.

## Exercise 8: Currency Conversion
Ask for USD amount and exchange rate. Calculate and display EUR.

## Exercise 9: Personal Profile
Ask for name, age, and city. Display formatted: `Name is Age and from City`

## Exercise 10: Multi-step Calculation
Ask for hours worked and hourly rate. Calculate pay after 20% tax. Display net pay.

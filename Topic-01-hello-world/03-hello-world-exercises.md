# Topic 1: Hello World - Exercises

## Exercise 1: Exact Output
Write a program that displays exactly:
```
Hello, World!
```

## Exercise 2: Welcome Message
Write a program that displays:
```
Welcome to Python Programming
```

## Exercise 3: Multiple Lines
Write a program that displays:
```
Line 1
Line 2
Line 3
```

## Exercise 4: With Numbers
Write a program that displays:
```
The answer is 42
```

## Exercise 5: Personal Information
Write a program that displays:
```
Name: Alice
Age: 25
City: New York
```

## Exercise 6: Formatted Output
Write a program that displays:
```
Score: 95
Grade: A
Status: Passed
```

## Exercise 7: Simple Story
Write a program that displays:
```
Once upon a time
There was a student
Learning Python
```

## Exercise 8: Math Result
Write a program that displays:
```
2 + 2 = 4
```

## Exercise 9: Quoted Text
Write a program that displays:
```
She said "Hello"
```

## Exercise 10: Professional Output
Write a program that displays:
```
===============
GRADE REPORT
===============
Student: Bob
Grade: A
Date: Today
===============
```

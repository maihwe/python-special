# Topic 7: Arithmetic - Exercises

## Overview

These exercises build from simple calculations to complex real-world scenarios. Each exercise reinforces arithmetic operators, order of operations, and practical problem-solving with math.

---

## Exercise 1: Simple Arithmetic

**Write a program that:**
- Asks user for two numbers
- Performs all basic operations (+, -, *, /)
- Displays all results

**Example interaction:**
```
First number: 10
Second number: 3
10 + 3 = 13
10 - 3 = 7
10 * 3 = 30
10 / 3 = 3.333...
```

**Concepts:** Basic operators, multiple operations

---

## Exercise 2: Order of Operations

**Write a program that:**
- Shows an expression with mixed operators
- Calculates result step by step
- Explains which operation happens first

**Example:**
```
Expression: 2 + 3 * 4
Step 1: Multiplication first (3 * 4 = 12)
Step 2: Then addition (2 + 12 = 14)
Result: 14
```

**Concepts:** PEMDAS, operator precedence

---

## Exercise 3: Even or Odd

**Write a program that:**
- Asks for a number
- Uses modulo to determine if even or odd
- Displays the result with explanation

**Example interaction:**
```
Enter a number: 15
15 % 2 = 1
15 is ODD

Enter a number: 24
24 % 2 = 0
24 is EVEN
```

**Concepts:** Modulo operator, conditional logic

---

## Exercise 4: Temperature Conversion

**Write a program that:**
- Asks for temperature in Celsius
- Converts to Fahrenheit (F = C × 9/5 + 32)
- Displays both values

**Example interaction:**
```
Celsius: 25
Fahrenheit: 77.0

Celsius: 0
Fahrenheit: 32.0
```

**Concepts:** Formula implementation, float conversion

Test 1: 85
Test 2: 92

## Exercise 6: Percentage Discount

**Write a program that:**
- Asks for original price
- Asks for discount percentage
- Calculates discount amount and final price
- Displays breakdown

**Example interaction:**
```
Original price: 50.00
Discount (%): 20
Discount amount: $10.00
Final price: $40.00
```

## Exercise 7: Compound Interest

**Write a program that:**
- Asks for principal, interest rate, and years
- Calculates final amount using: A = P(1 + r)^t
- Displays interest earned

**Example interaction:**
```
Principal: 1000
Interest rate (%): 5
Years: 10
Final amount: $1628.89
Interest earned: $628.89
```

**Concepts:** Exponents, formula application

## Exercise 8: BMI Calculator

**Write a program that:**
- Asks for weight (kg) and height (m)
- Calculates BMI (weight / height²)
- Categorizes: underweight, normal, overweight, obese

**Example interaction:**
```
Weight (kg): 70
Height (m): 1.75
BMI: 22.9
Category: Normal weight
```

**Concepts:** Power operator, conditional categories

## Exercise 9: Tip Calculator

**Write a program that:**
- Asks for bill amount
- Asks for tip percentage

**Example interaction:**

Bill amount: $45.00
Tip percentage: 20
Tip: $9.00

Other options:

## Exercise 10: Complex Calculation - Loan Payment

**Write a comprehensive program that:**
- Asks for loan amount, annual interest rate, and years
- Calculates total interest (simple interest: I = P × r × t)
- Calculates total to pay
- Calculates monthly payment
- Displays full breakdown

**Example interaction:**
```
Loan amount: $10000
Annual interest rate (%): 6
Loan period (years): 5
Interest: $3000.00
Total to pay: $13000.00
Monthly payment: $216.67
```

**Concepts:** Multi-step calculations, real-world formulas

## Tips for Success

1. **Break it down:** Use multiple variables for clarity
2. **Order matters:** Be careful with order of operations
3. **Test edge cases:** What if numbers are zero or negative?
4. **Format output:** Use f-strings with decimal places for money
5. **Use parentheses:** They make complex formulas clearer
